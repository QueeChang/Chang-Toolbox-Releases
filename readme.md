# Chang Toolbox Releases

Repository dedicato alla pubblicazione degli artefatti di release di [Chang-Toolbox](https://github.com/QueeChang/Chang-Toolbox).

## Uso

Il codice sorgente e le modifiche si trovano nel repository principale. Questo repository deve contenere esclusivamente gli installer, i file di aggiornamento e gli eventuali metadati necessari alla distribuzione delle versioni pubblicate.

Per contribuire al programma, apri una modifica in [Chang-Toolbox](https://github.com/QueeChang/Chang-Toolbox). Per aggiungere o aggiornare una release, verifica che asset, checksum, firma e metadati siano coerenti prima della pubblicazione.
